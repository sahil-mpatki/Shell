What’s inside

A kernel that learns your workload

Linux 6.18 LTS built with Clang ThinLTO for -march=alderlake, BORE and the sched_ext LAVD scheduler, and a one-command AutoFDO + Propeller loop that recompiles it from profiles of your own machine.

Memory that stays responsive

zram with lz4 and idle recompression to zstd, MGLRU thrash protection, and shellos-senpai, a pressure-driven reclaimer modelled on Meta’s TMO.

Snapshots you can boot

Btrfs with Snapper. Every apt run takes a snapshot, the Limine menu lists them, and shellos-rollback makes any of them your system again.

Eight desktops, one login screen

Tick as many as you like in the installer and pick one at each login. Change your mind later with shellos-desktops add or remove.

Sensible defaults

zsh with starship, Alacritty, Firefox from Mozilla’s repo, Flatpak with Flathub, and Distrobox with Podman for everything else.

Built in the open

Every package is built by GitHub Actions from pinned sources, signed, and published to an apt repository. Each ISO is boot-tested in a VM before it’s released, and your desktop lets you know when a new one is out.

    Verify, then try it in a VM

    sha256sum -c shellos-*.iso.sha256
git clone https://github.com/sahil-mpatki/Shell && cd Shell
vm/shellos-vm live ../shellos-*.iso

    Then write it to a USB stick and boot it:

    sudo dd if=shellos-*.iso of=/dev/sdX bs=4M status=progress oflag=sync

    Requirements

    • x86-64 CPU with Alder Lake-class extensions: Intel 12th gen or newer, or AMD Zen 3+
    • UEFI firmware, Secure Boot off
    • 4 GB RAM and 24 GB of disk; network during install for desktops other than COSMIC

    Already on Debian trixie?

    ShellOS’s packages live in a signed apt repository on this site.

    curl -fsSL https://sahil-mpatki.github.io/Shell/apt/shellos-archive.asc | sudo tee /etc/apt/keyrings/shellos-archive.asc
echo "deb [signed-by=/etc/apt/keyrings/shellos-archive.asc] https://sahil-mpatki.github.io/Shell/apt trixie main" | sudo tee /etc/apt/sources.list.d/shellos.list
